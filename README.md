# U.C.B.R — app para Windows

**Baixar:** [UCBR-Setup.exe](https://github.com/guilhermeazevedo2899-bot/ucbr-app/releases/latest/download/UCBR-Setup.exe)

Na primeira instalação o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações** > **Executar assim mesmo**.
O app se atualiza sozinho quando sai versão nova.

---
Desenvolvido por Guilherme Azevedo.

### Para gerar uma versão nova
1. Atualize `site/` (plataforma) e `version` no `package.json` (ex.: 1.58.0).
2. Envie a tag `v1.58.0`. O GitHub Actions gera o instalador e publica a release sozinho.
